# pub-critic

Скилл для Claude.

Редактор-консультант по публицистике. Оценивает черновики и наработки по трём осям — идея, форма, читаемость — и выносит один вердикт: ДЕЛАТЬ, НЕ ДЕЛАТЬ или ДОДЕЛАТЬ. Каждое замечание привязано к конкретному месту в тексте.

## Когда использовать

- Понять, стоит ли дописывать материал
- Получить редакторский разбор черновика
- Оценить тезис или аутлайн до того, как писать

Не подходит для переписывания текста (author-in-residence, punker, humanizer) и оценки бизнес-идей.

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/pub-critic.git ~/.claude/skills/pub-critic
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `pub-critic`.
